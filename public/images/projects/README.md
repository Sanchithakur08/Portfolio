# Project screenshots

Add one screenshot per project here (recommended 1600x1000 px, 16:10, PNG/JPG/WebP, under ~300 KB):

- smarthire.webp
- assettrack.webp
- chatverse.webp

Then set the `image` field for each project in `src/data/projects.ts`, e.g. `image: '/images/projects/smarthire.webp'`.
Make sure screenshots contain no confidential data, real user data, or credentials.

Your profile photo goes in `public/images/` (e.g. `profile.jpg`, square, ~800x800 px). Set `photo` in `src/data/profile.ts`.
